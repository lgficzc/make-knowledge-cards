# make-knowledge-cards

把一篇文章（或一个 `.md` / `.txt` 文件）整理成 5~8 张能直接复习的知识卡片。

一张卡只讲一个知识点；每条结论都能在原文找到依据；信息不够就少给几张，不硬凑、不编造。

## 特点

- **限数量**：默认 5~8 张。低于 5 张时在开头写明原因（信息有限 / 多为观点 / 大量离题），高于 8 张时合并次要项，不把两条知识硬塞进一张卡。
- **单点**：一张卡一个知识点，同义改写和重复表述合并。
- **有据**：只用原文的事实、数字、条件；不补原文没有的建议、最佳实践、替代方案或新因果。
- **区分事实与观点**：原文里没有依据的断言只作"原文观点"保留，标注为经验判断。
- **按文本类型调整**：教程按操作顺序排、警告单独成卡；观点文标注"以下为原文观点"；会议纪要只取决定，用"检查：负责人 / 时间 / 动作"替代例子。
- **不输出过程**：只给总览和卡片，不展示提取、淘汰、自检的过程。

## 输入与输出

**输入**：粘贴的正文，或本地 `.md` / `.txt` 文件路径。

**输出**：一行总览 + Markdown 卡片。每张卡片固定四段：

```markdown
### 卡片 1：<标题>
**核心知识**：<一句话结论，约 50 字>
**简明解释**：<2~4 句：依据、条件、机制>
**例子或自测**：<原文例子，或自测题＋一句话答案>
```

用户要求保存时，写到原文同目录的 `<原文件名>.cards.md`。

## 示例

输入：

> 番茄工作法把工作切成 25 分钟一段，每段后休息 5 分钟，四个循环后休息 15~30 分钟。它的作用是给注意力设定明确的开始和结束，减少"什么时候才能停"的决策消耗。如果任务需要连续思考超过 25 分钟，比如写长文、调试复杂问题，频繁打断反而会增加重新进入状态的成本。

输出：

```markdown
共 2 张卡片：番茄工作法怎么用

### 卡片 1：固定时段减少注意力决策消耗
**核心知识**：25 分钟工作加 5 分钟休息的固定节奏，减少了"什么时候开始、什么时候停"的决策消耗。
**简明解释**：开始和结束时间被固定成默认流程，不必每次都重新决定要不要继续，注意力更容易留在任务上。
**例子或自测**：自测：为什么番茄钟适合开始容易拖延的人？参考答案：开始被压缩成一个 25 分钟的短承诺，而且结束时间是确定的。

### 卡片 2：连续思考型任务不宜切得太碎
**核心知识**：需要连续思考超过 25 分钟的任务，被频繁打断后重新进入状态的代价可能高于休息收益。
**简明解释**：写长文、调试复杂问题依赖持续的上下文；中断会丢思路，恢复上下文要额外时间。
**例子或自测**：原文例子：写长文、调试复杂问题时频繁打断，会增加重新进入状态的成本。
```

（这段输入只够 2 个知识点，所以只有 2 张卡。）

## 安装

Skill 本体在 `skills/make-knowledge-cards/`。仓库里的 `skills/` **不是** DSH 的默认扫描根，需要复制或链接到下面任一位置：

| 位置 | 生效范围 |
|---|---|
| `<项目>/.dsh/skills/` | 当前项目 |
| `<项目>/.agents/skills/` | 当前项目（兼容其他 agent 工具） |
| `~/.dsh/skills/` | 当前用户的所有项目 |
| `~/.agents/skills/` | 当前用户的所有项目（兼容） |

```powershell
# 项目内安装
New-Item -ItemType Directory -Force .dsh\skills | Out-Null
Copy-Item -Recurse skills\make-knowledge-cards .dsh\skills\

# 或全局安装
Copy-Item -Recurse skills\make-knowledge-cards "$env:USERPROFILE\.dsh\skills\"
```

装完刷新/重开 DSH 的 Skills 列表即可看到。支持 `SKILL.md` 的其他工具可以直接使用 `skills/make-knowledge-cards/` 目录；`agents/openai.yaml` 提供界面用的显示名、简介和默认提示词。

## 使用

用自然语言触发，例如：

- 「把 `notes/睡眠与记忆.md` 做成知识卡片」
- 「用 make-knowledge-cards 整理下面这篇文章」
- 「把这段会议纪要提炼成知识卡片」
- 「把这篇文章整理成复习提纲」

触发词覆盖：做成知识卡片、复习卡片、提炼知识点、整理成复习提纲、拆解文章。

## 不支持

- 网页链接抓取 —— 请粘贴正文
- PDF、Word、图片、扫描件 —— 请转成 `.md` / `.txt` 或粘贴文字
- Anki 导出、图形界面、卡片配图

遇到不支持的输入，Skill 会一句话说明限制并给出替代做法，不凭文件名或链接猜内容。

## 规则要点

| 维度 | 规则 |
|---|---|
| 数量 | 目标 5~8 张；不足写原因，超了合并或舍弃边缘项 |
| 取材 | 保留原理因果、方法步骤、判断标准、反直觉结论、关键数字、决定与结论 |
| 丢弃 | 背景铺垫、作者经历、情绪修辞、重复表述、无依据断言（降级为"原文观点"） |
| 解释边界 | 只用原文依据；可以解释术语含义，不写原文没有的最佳实践 |
| 字段 | 标题 6~16 字；核心知识一句判断；解释 2~4 句；例子或自测题 + 一句话答案 |
| 自检 | 数量、单点、有据、无越界、保真、例子、类型、语言 |

## 校验

仓库自带纯标准库校验器，不需要第三方依赖：

```powershell
python scripts/quick_validate.py .
```

没有可用的 `python` 时（例如 Windows 上的 Store 别名），改用本机 DSH 运行时自带的解释器执行同一条命令即可。

检查项：frontmatter 是否存在、`name` 是否符合 `^[a-z0-9]+(-[a-z0-9]+)*$` 且与目录名一致、`description` 长度、正文长度、skill 目录顶层文件是否越界、`agents/openai.yaml` 的 `interface` 元数据。通过时输出：

```
PASS: 1 skill(s), 0 warning(s), 0 error(s)
```

有错误时退出码为 1，方便接到 CI 里。

## 实测

用四类文本生成过卡片并逐条核对，暴露的问题都已写回 `SKILL.md`：

| 文本类型 | 实测结果 |
|---|---|
| 科普长文（1046 字） | 6 张，数字与结论保真 |
| 操作教程（1277 字） | 8 张，警告与参数单独成卡 |
| 观点评论（612 字） | 5 张，卡内标注为经验判断 |
| 会议纪要（654 字） | 3 张，只留决定，用检查项替代例子 |

## 常见问题

**装好了但在 DSH 里看不到？** 确认目录在 `.dsh/skills/`、`.agents/skills/` 或 `~/.dsh/skills/` 下，而不是仓库的 `skills/`；然后刷新 Skills 列表。

**只生成了 3 张，是不是坏了？** 不是。原文信息不足、观点多论据少、或是会议纪要时，按规则只给站得住的卡片，并在开头写明原因。

**卡片里出现了原文没有的建议？** 这是规则明确禁止的（自检项"无越界"）。遇到就说明提取时越界了，可以把原文和输出一起反馈，据此补充规则。

**英文文章可以吗？** 可以，卡片语言跟随原文；中英混排时保留英文术语原词。

**文件读出来是乱码？** Skill 会按 GB18030 重新解码再处理；仍失败请另存为 UTF-8 后重试。
